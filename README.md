# Softnava

Sitio estático de Softnava con una portada animada, transiciones y efectos de entrada en sus páginas independientes para inicio, servicios, quiénes somos, misión, visión y equipo.

Abre `index.html` en un navegador para ver la portada. Al pulsar «Explorar nuestros servicios», la página principal aparece enseguida mientras suena «¡Hola! Bienvenido a Softnava». El botón de sonido permite repetir la bienvenida. El botón flotante de WhatsApp abre el chat al +57 301 946 2759 con el mensaje «Hola Softnava, quiero información sobre sus servicios.». El sitio no necesita servidor.

Los servicios incluidos son desarrollo web, soporte y mantenimiento, ideas digitales y bases de datos. La página de servicios presenta modalidades orientativas; los enlaces de contacto abren WhatsApp. El apartado Proyectos abre una página independiente con el caso de Kdulce Pastel. La portada y la página de servicios presentan el sistema de información desarrollado por Softnava para Kdulce Pastel.

En el caso de Kdulce Pastel se puede alternar entre el logo y el video del proyecto.
